# Audio Resources

For legal compliance and copyright protection (DMCA), copyrighted commercial audio files (including *"Từng Ngày Yêu Em"* by Bùi Trường Linh) are not redistributed in this public repository.

### Audio Options:
1. **Built-in Web Audio API Synthesizer (Active by default)**:
   When no local MP3 file is hosted in this repository, the application automatically activates a soothing harmonic music box chime via the Web Audio API, which drives the audio visualizer, flower sway phases, and mascot bob/tilt at 60 FPS without external file dependencies.
2. **Local / Self-hosted Audio**:
   To play your own audio file, simply place your licensed MP3 file in this directory with the filename `tung-ngay-yeu-em.mp3`. The player will automatically load and synchronize the garden's motion to your track.
